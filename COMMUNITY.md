# Community Feedback

You do **not** need to be a game developer to participate.

This repository is an open game-design concept. If a mechanic sounds fun, reacting to it is already useful.

## Start Here

For casual reactions, questions, polls, or new ideas, use:

👉 **[GitHub Discussions](https://github.com/mero807/time-leap-arpg-game-design/discussions)**

You do not need to write anything technical.

If you only want to react to one specific mechanic, each major concept also has its own thread:

1. [Time Leap — knowledge survives, power rewinds](https://github.com/mero807/time-leap-arpg-game-design/issues/1)
2. [Hidden Jobs — discover classes through strange conditions](https://github.com/mero807/time-leap-arpg-game-design/issues/2)
3. [Causality Distortion — changing history creates new content](https://github.com/mero807/time-leap-arpg-game-design/issues/3)
4. [Adaptive Bosses — bosses react to player habits](https://github.com/mero807/time-leap-arpg-game-design/issues/4)
5. [Living World — no mandatory main quest](https://github.com/mero807/time-leap-arpg-game-design/issues/5)
6. [Buildcraft — systems combine into unexpected builds](https://github.com/mero807/time-leap-arpg-game-design/issues/6)

If you like a concept:

- leave a 👍 reaction on its thread
- comment with what sounds fun
- suggest a variation
- share the concept thread with someone else
- Star the repository if you like the overall direction

There is no expectation that anyone joins a development team.

## What Feedback Is Useful?

Examples:

- "I would play a game with this mechanic."
- "This part sounds tedious; I would change it like this."
- "This reminds me of another game, but the time-leap twist is interesting."
- "I like the boss AI concept more than the 100-job idea."
- "This would be better in 2D."
- "I want the world to remember previous timelines."

Simple reactions are useful too.

## Why Separate Concept Threads?

The full design is large.

Someone may not care about the entire game but strongly like one system.

Separate threads make it possible to see which ideas resonate independently.

The repository itself is the source of truth. Discussions and concept threads are lightweight community surfaces for reactions, polls, questions, and new variations.
