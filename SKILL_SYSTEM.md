# Skill System

## Current Slot Structure

Current decision:

- **4 active skill slots**
- **1 separate ultimate slot**

A character may learn more than four active skills, but choosing which four to equip is part of buildcraft.

## Controller Access

Current candidate:

- L2 + Square -> Skill 1
- L2 + Triangle -> Skill 2
- L2 + Circle -> Skill 3
- L2 + Cross -> Skill 4
- separate button -> Ultimate

The exact layout can change later.

## Ways to Learn Skills

Skills may come from multiple sources.

### Job-Innate Skills
Available because the current job owns them.

### Hidden Skills
Unlocked through secret conditions.

### Mastery Evolution
A skill gains alternate forms after enough use or mastery.

### Skill Fusion
Two or more mastered skills plus a contextual condition produce a new skill.

### World Discovery
Tomes, dead spirits, teachers, relics, bosses, historical echoes, or unique locations can reveal skills.

Different job families may learn skills in different ways.

Examples:

- Mage -> books / research
- swordsman -> combat insight
- Necromancer -> communication with the dead
- Berserker -> near-death triggers

## Skill Mastery

Using a skill can increase mastery.

Mastery can unlock:

- improved properties
- branching forms
- new interactions
- fusion eligibility
- hidden job conditions

The mastery curve should avoid requiring mindless repetition.

## Evolution

A mastered skill may reveal several evolution choices.

Preferred philosophy:

> Discovering an evolution should not necessarily destroy the original skill forever.

Example:

Fireball -> Explosive Fireball / Piercing Fireball / Delayed Fireball

## Skill Fusion

Skill fusion is one of the major hidden-build systems.

Example:

- Fireball Mastery 10
- Wind Cutter Mastery 10
- cast both during a specific storm condition
- result: Firestorm discovered

The player should not always receive the full checklist in advance.

Possible UI:

Unknown Fusion

- Fire skill mastery condition — satisfied
- ???
- ???

Clues can gradually reveal missing conditions.

## Skill Limits

Active skills should usually be constrained by one or more of:

- cooldown
- job resource
- charges
- status requirement
- health cost
- positional requirement
- setup requirement
- environmental condition

Cooldowns are part of the current direction, but not every job needs identical cooldown rules.

Examples:

- Mage -> Mana + cooldown
- Berserker -> Rage + health risk
- Assassin -> charges refreshed through execution
- Necromancer -> Soul cost

## Passive Skills

Passive skills can exist, but they should not become an unreadable pile of tiny percentage bonuses.

Prefer passives that alter behavior.

Examples:

- dodging through an enemy marks them
- fear increases attack speed
- curse becomes a resource
- summoned undead inherit status effects
- charged attacks consume armor instead of stamina

## Status Effects as Build Resources

Statuses are not only enemy debuffs.

Possible normal statuses:

- Poison
- Burn
- Freeze
- Bleed
- Shock

Possible mental/world statuses:

- Fear
- Madness
- Curse
- Corruption

A player may intentionally maintain a harmful status because a job converts it into power.

Example:

Fear active -> attack speed increases -> hidden assassination interaction becomes available

A maximum Madness state could reveal an NPC or map invisible to normal characters.

## Ultimate

The ultimate is separate from the four active skills.

It should feel like a defining expression of the job rather than simply "Skill 5."

Its resource may be:

- combat charge
- job resource
- long cooldown
- event condition
- accumulated damage
- successful counters
- defeated enemies

Different job families may charge ultimates differently.

## Time-Leap Interaction

Physical skill progression rewinds with time unless a specific rule says otherwise.

However, **knowledge that a skill or fusion exists** may persist.

This creates situations where the player knows what to pursue in an earlier period even though they no longer physically possess the skill.

Exact persistence flags must be standardized in the time system.
