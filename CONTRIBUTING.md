# Contributing / Reusing This Design

## Short Version

You do not need permission to use these ideas.

The design documents are dedicated to the public domain under **CC0 1.0 Universal**.

You may:

- copy them
- modify them
- translate them
- fork the repository
- implement individual mechanics
- build a game based on the entire concept
- use the ideas in a completely different genre
- use them commercially

Attribution is appreciated if you personally want to give it, but it is **not required**.

---

## This Is Not a Managed Team Project

The original author does not promise:

- active development
- code review
- project management
- meetings
- feature decisions
- long-term maintenance
- participation in derivative projects

If you like something here, feel free to take it and build your own interpretation.

---

## Pull Requests

Pull requests are welcome if they improve clarity or contribute interesting design ideas, but there is no guarantee of review or merge.

Forking is always acceptable.

---

## Design Status Labels

When adding or changing ideas, it is useful to distinguish:

### Current Direction
A design decision that currently represents the concept.

### Candidate
A strong possibility that is not final.

### Experimental Idea
Interesting but not yet accepted.

### Open Question
Intentionally unresolved.

This avoids turning brainstorming into accidental canon.

---

## Implementation Philosophy

Anyone implementing the design should feel free to shrink it.

A strong small game is better than an unfinished giant one.

A good starting slice might include:

- one small region
- 3–4 jobs
- one hidden job
- one adaptive boss
- four active skills
- one ultimate
- one meaningful time-rewrite event

If that is fun, expand.

If not, change the design.
