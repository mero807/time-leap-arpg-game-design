# GitHub Discussions Setup

GitHub Discussions is enabled and is intended as the friendlier community layer for people who do not want to use Issues.

The remaining setup is to create the initial categories/posts and use Discussions as the main casual-feedback entry point.

## Recommended Categories

Keep it small:

### Ideas
For reactions to individual mechanics and new variations.

### Polls
For lightweight voting.

### General
For anything that does not fit elsewhere.

Avoid creating too many categories at the beginning.

---

## First Poll

### Title

Which part of this game concept interests you most?

### Body

This is an open game-design concept, not a recruitment post.

You do not need to be a developer.

Which idea would most make you want to try the game?

### Options

- Time Leap — rewrite history, but only knowledge survives
- Hidden Jobs — discover classes through strange conditions
- Causality Distortion — changing history creates anomalies
- Adaptive Bosses — bosses react to player habits
- Living World — factions and events move without a mandatory main quest
- Buildcraft — many systems combine into unexpected builds

Full design:
https://github.com/mero807/time-leap-arpg-game-design

## Suggested First General Post

### Title

What would make this concept more fun for you?

### Body

I am not building a development team here.

This repository is simply an open game-design concept released under CC0.

If you are a player rather than a developer, that is completely fine.

I would be interested in things like:

- which mechanic sounds most fun
- which mechanic sounds annoying
- what you would remove
- what you would simplify
- what combination of systems sounds exciting

Short reactions are welcome.
